# VOC2007 实验结果

评估协议：VOC2007 十一点 AP，IoU=0.5。train 更新权重，val 选择模型；以下结果来自服务器实际日志。测试集共4952张图片。

| 实验 | 最佳验证 mAP@0.5 | 测试 mAP@0.5 |
|---|---:|---:|
| baseline | 28.29% | 30.48% |
| continue512 | 28.83% | 未评估 |
| multiscale640 | 34.66% | 36.15% |

baseline：自定义轻量骨干+FPN+Faster R-CNN，从零训练30轮，输入短边512。

continue512：从baseline最佳权重初始化，再训练30轮，保持512，使用学习率预热与余弦衰减。优化器重新初始化。

multiscale640：同样从baseline最佳权重初始化，再训练30轮；训练尺度480/576/640，评估固定640，使用预热与余弦衰减。根据验证结果选择此模型进行最终测试。

相比baseline，multiscale640验证提高6.37个百分点，测试提高5.67个百分点。该实验同时改变训练预算、优化策略、输入分辨率和多尺度设置，不能将全部提升单独归因于多尺度。尚未做固定640的消融，也未做多随机种子实验。

各子目录保存实际配置、历史和分类别AP。模型权重与数据集仅在本地/服务器保留，不随仓库上传。完整命令见上级README。
